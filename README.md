- 🚀 [**Portfolio-Website**](https://github.com/saitarun18/Portfolio-Website) — Premium developer portfolio built with **Next.js 15** (App Router, RSC), **React 19**, **TypeScript** and **Tailwind v4**: Framer Motion animations, a ⌘K command palette and a graceful-degradation contact backend.
